================================================================================
TROUBLESHOOTING:
================================================================================

Q: Chart tidak muncul di PDF/Excel?
A: Pastikan chart sudah ter-render di halaman sebelum export.
   Scroll ke bawah dulu untuk load semua chart.

Q: Download PDF/JPEG detail tidak jalan?
A: Pastikan browser mendukung html2canvas.
   Gunakan Chrome/Firefox/Edge versi terbaru.

Q: Data hilang setelah clear browser?
A: Data di localStorage akan terhapus jika clear data browser.
   Selalu export Excel sebagai backup.

Q: Surat preview tidak muncul?
A: Pastikan file yang diupload adalah gambar (JPG/PNG).
   PDF bisa di-upload tapi preview terbatas.
